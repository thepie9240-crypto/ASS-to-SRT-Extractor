This software converts anime / video subtitle files from .ass (Advanced SubStation Alpha)
format into plain .srt format, keeping ONLY the dialogue (the spoken lines).

Why is it needed?
An .ass subtitle file usually contains much more than dialogue: opening/ending song lyrics,
karaoke effects, on-screen signs and titles, drawings and other styling data. Many players,
translation tools and editing programs only understand simple .srt files, and extra content
like songs and signs makes the result messy.

What it does:
 - Load one or many .ass / .ssa files (drag & drop or the "Add files" button).
 - Lists every "style" found in the files (Default, Italics, OP, ED, Signs, etc.) and
   guesses what each one is (Dialogue, Song, Sign/Title, Drawing/FX).
 - You tick only the styles you want to keep.
 - "Smart pick" (Levels 1-3: Quick, Balanced, Strict) can choose the dialogue styles
   automatically.
 - You can preview the lines of any style before converting.
 - Converts all loaded files to clean .srt files in one click, saved next to the original
   files or in an output folder you choose.

Typical use: turning a whole season of anime .ass subtitles into clean, dialogue-only
.srt files.
